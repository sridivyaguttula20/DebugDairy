Understand the Mistake

Analysis summary

⚠ What went wrong?

The loop condition allows the index to reach the array length, which is not a valid array index.

⌕ Where is the mistake?

The loop condition should stop before the index reaches the array length.

i <= arr.length

◇ Why did it happen?

Java arrays use zero-based indexing. An array of length 3 has valid indexes 0, 1, and 2.

✓ How to correct it?

Change the loop condition to i < arr.length so the loop stays within valid array indexes.

⌘ Corrected Code

int[] arr = {10, 20, 30};

for (int i = 0; i < arr.length; i++) {
